# 🩸 สายเลือดอมตะ — Bloodline of the Eternal God
**CK3 Version:** 1.19.0.x (Scribe)

## วิธีติดตั้ง
1. แตกไฟล์ไปที่ `Documents/Paradox Interactive/Crusader Kings III/mod/`
2. เปิดเกม → Mods → เปิด **สายเลือดอมตะ**

## วิธีใช้งาน
- **Ruler Designer**: เลือก trait "สายเลือดอมตะ" ตอนสร้าง custom character
- **Console command**: `add_trait eternal_bloodline`

## ความสามารถทั้งหมด
| ด้าน | ค่า |
|---|---|
| อมตะ | ไม่แก่ ไม่ตาย ไม่ป่วย |
| ไม่มีวัยล้มตาย | immortal = yes |
| แผนการสำเร็จ 100% | owned_scheme_success_chance +100% |
| วัฒนธรรม 5× | cultural_fascination_progress ×5 |
| ค่า Stat ทุกด้าน | +8 (Prowess +12) |
| รายได้ | +5 gold/เดือน |
| Prestige | +50%/เดือน |
| Dread | +100% gain |
| Intimidation | +30 |
| ความคิดเห็น vassal | +20 |
| ความคิดเห็น clergy | +15 |
| Army damage | +50% |
| MaA maintenance | -50% |
| ป้องกันแผนศัตรู | -100% |

## ข้อสำคัญ
- **ไม่สุ่มให้ NPC เด็ดขาด** (random_creation_weight = 0)
- ต้องสร้าง custom character เท่านั้น
- ลูกมีโอกาส inherit 15%

## เนื้อเรื่อง
*"ในยุคที่เทพเจ้ายังเดินบนแผ่นดิน มีสายเลือดหนึ่งที่ถูกสาปและอวยพรพร้อมกัน — สายเลือดแห่งความเป็นนิรันดร์..."*
